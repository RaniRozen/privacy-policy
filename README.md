# הזמנה לבר המצווה של רני

אתר הזמנה + אישורי הגעה + מסך ניהול פרטי. ללא תלויות – רק Node 18+.

## הרצה מקומית
    ADMIN_PASSWORD='הסיסמה-שלך' node server.js
- אתר האורחים: http://localhost:3000
- ניהול (רק עם הסיסמה): http://localhost:3000/admin

בלי `ADMIN_PASSWORD` תיווצר סיסמה אקראית שתודפס בטרמינל.

## אבטחה
- כל נתוני האורחים נגישים רק דרך `/api/admin/*`, שדורש עוגייה חתומה (HttpOnly) שמתקבלת רק אחרי סיסמה נכונה.
- הגבלת ניסיונות כניסה (8 ל-15 דקות), והגבלת קצב לשליחת אישורים.
- הסיסמה נשמרת רק במשתנה סביבה – לא בקוד. החליפו סיסמה = כל החיבורים מתנתקים.

## העלאה לאינטרנט (למשל Render / Railway / Fly)
1. צרו Web Service מהריפו הזה, Start command: `node server.js`.
2. הגדירו משתנה סביבה `ADMIN_PASSWORD` (סיסמה חזקה).
3. **אחסון חינמי (מומלץ):** צרו Redis חינמי ב-upstash.com והגדירו `UPSTASH_REDIS_REST_URL` ו-`UPSTASH_REDIS_REST_TOKEN`. האישורים יישמרו שם גם אחרי הפעלה מחדש.
   אחרת, **חשוב:** הנתונים נשמרים בקובץ `data/rsvps.json`. הוסיפו Persistent Disk וכוונו אליו עם `DATA_DIR=/הנתיב/לדיסק`, אחרת הנתונים יימחקו בכל פריסה מחדש.
4. הפעילו HTTPS (ברירת מחדל בשירותים האלה).
